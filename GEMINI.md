# Instructions for AI assistants

The single source of truth for working in this repository is **AGENTS.md** at
the repository root.

Before you read code, answer questions or edit anything:

1. Read `AGENTS.md` completely and follow its mandatory reading order
   (`docs/shared/README.md` lists every document).
2. Follow `docs/shared/RULES.md` — breaking those rules has caused outages.
3. When you finish any change, follow `docs/shared/DOCUMENTATION_PROTOCOL.md`
   (update docs, add a `docs/shared/WORK_LOG.md` entry, mirror `docs/shared/`
   to the sibling repository).

Everything written into this repository (code, UI text, comments, commits,
docs) must be in English.
